## AI Summary

I have enough context for a first draft. A few findings changed the design:

- **`<img src>` can't send the `Authorization: Bearer` header** that every API route requires (`HTTPBearer` in `common/dependencies.py`). How images are served is therefore the central decision.
- **The projector never shows answer options.** The host `QuestionPage` renders only the prompt; players see the options as tiles on their phones. Option images therefore matter most on the **player** side.
- **Prompts are sanitised with `bleach`**, which allows only `b, i, br, u`, so an `<img>` tag can't go inside the prompt text.
- **Pillow isn't a dependency**, and **courses can't be deleted** (no route exists).
- **The `buzzer/game` bundle is `version: 1`**, and the importer rejects any other version.
