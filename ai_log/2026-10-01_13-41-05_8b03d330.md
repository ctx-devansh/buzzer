## How it runs

```
             ┌──────────── nginx (:80) ───────────────┐
 browser ──► │ /host/  /player/  /admin/  → built SPAs │
             │ /api/        → backend (REST)           │
             │ /socket.io/  → backend (WebSocket)      │
             └─────────────────┬──────────────────────┘
                               ▼
                   backend (FastAPI + Socket.IO)
                      │                 │
                 MySQL 8.0          Redis 7
            (permanent record)   (live game state)
```

[docker-compose.yml](docker-compose.yml) starts four services: `nginx`, `backend`, `mysql` and `redis`. [nginx/nginx.dev.conf](nginx/nginx.dev.conf) routes requests by path, as shown above.
